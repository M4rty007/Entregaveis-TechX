# Buscador de CEP e Mini Pokédex

Projeto de prática de validação de dados, arrays, Promises, `async/await`,
Fetch API e manipulação dinâmica do DOM.

## Como executar

Abra `index.html` no navegador. Se o navegador bloquear as requisições ao
abrir o arquivo diretamente, inicie um servidor local na pasta do projeto:

```bash
python -m http.server 8000
